# Figures Module

Reproducible paper figure generation.

## Architecture

This module will generate the figures proposed in `paper.md`:

- overall federated legal LLM framework
- cross-jurisdiction aggregation mechanism
- multi-agent judicial debate workflow
- privacy-preserving communication pipeline
- conflict-aware aggregation architecture

Future figure scripts should write source data and rendered outputs to `outputs/figures`.

## Usage

No runtime API is implemented yet.
