# Revision result snapshot

Privacy is complete: five conditions × seeds 41–43 = 15 runs. The privacy folder
contains all run summaries, paired contrasts, reliability-bin source data and
figures. Analysis is generated by `scripts/analyze_revision_v2.py`.
`privacy/source_runs/` contains the 15 resolved configurations, per-round metrics,
aggregation and threshold audits, test probabilities, membership loss features,
and original attack metrics. These artifacts contain benchmark identifiers and
numeric predictions, with no case text.

```bash
python scripts/analyze_revision_v2.py --kind privacy --input papers/ipm/results/revision_v2/privacy/source_runs --output tmp/reproduced_privacy
python scripts/run_membership_inference_attack.py --features papers/ipm/results/revision_v2/privacy/source_runs/revision_v2_privacy_no_clip_en-pl_seed41/membership_features.jsonl --output tmp/reproduced_attack --seed 41
```

CaseHOLD is a partial snapshot of the 40-run frozen protocol. Check
`casehold/analysis.json` for the exact completed/missing cells. It is not used as
a completed gate-effect result in the manuscript. Remaining runs continue on the
server; see `HANDOFF.md` for job identities and retrieval instructions.

The manuscript uses seed SD for plot bars and tables. Paired uncertainty intervals
use the training seed as the unit; test records are not independent repetitions
of the full training algorithm. Privacy uses trusted central aggregation, while
the loss attack tests record membership; read these outcomes separately.
