# Revision result snapshot

Updated 2026-11-08: the authoritative completed analyses are
`analysis/casehold_extended/` (45/45), `analysis/multieurlex/` (120/120),
`analysis/agents/` (6/6), and `analysis/privacy/` (15/15). LegalBench is 11/12;
`analysis/legalbench/` explicitly lists the missing Mistral reference. Earlier
partial snapshots below are retained as historical artifacts.

CaseHOLD worst-client accuracy is reconstructed using the identical four
round-robin test shards for every run. Eight early shared-only runs logged a
different grouping; `original_worst_client_accuracy` preserves those values.
Aggregate accuracy and matched gate effects are unchanged. Agent analysis now
includes parse counts, accuracy conditional on both outputs parsing, and costs.
LegalBench analysis reconstructs accuracy, macro F1, balanced accuracy, Brier and
ECE from saved predictions and records prediction-class and truncation counts.

The maintained CAS manuscript now includes these results. Partial LegalBench
publication is explicitly labelled; missing outcomes are never filled in. A new
200-case, five-training-seed reasoning confirmation is running remotely and is
not included as a completed result here. See `docs/experiments/REVIEW_20261108.md`
and `experiments/revision_v2/REASONING_CONFIRMATION.md`.

Privacy is complete: five conditions × seeds 41–43 = 15 runs. The privacy folder
contains all run summaries, paired contrasts, reliability-bin source data and
figures. Analysis is generated by `scripts/analyze_revision_v2.py`.
`privacy/source_runs/` contains the 15 resolved configurations, per-round metrics,
aggregation and threshold audits, test probabilities, membership loss features,
and original attack metrics. These artifacts contain benchmark identifiers and
numeric predictions, with no case text.

```bash
python scripts/analyze_revision_v2.py --kind privacy --input papers/ipm/results/revision_v2/privacy/source_runs --output tmp/reproduced_privacy
python scripts/run_membership_inference_attack.py --features papers/ipm/results/revision_v2/privacy/source_runs/revision_v2_privacy_no_clip_en-pl_seed41/membership_features.jsonl --output tmp/reproduced_attack --seed 41
```

CaseHOLD is a partial snapshot of the 40-run frozen protocol. Check
`casehold/analysis.json` for the exact completed/missing cells. It is not used as
a completed gate-effect result in the manuscript. Remaining runs continue on the
server; see `HANDOFF.md` for job identities and retrieval instructions.

The manuscript uses seed SD for plot bars and tables. Paired uncertainty intervals
use the training seed as the unit; test records are not independent repetitions
of the full training algorithm. Privacy uses trusted central aggregation, while
the loss attack tests record membership; read these outcomes separately.

## Extension snapshot

`analysis/casehold_extended/analysis.json` contains the joint CaseHOLD/FedAdam
progress snapshot. `casehold/source_runs/` and `casehold_fedadam/source_runs/`
retain numeric predictions, configurations and round logs. The corresponding
MultiEURLEX evidence is in `multieurlex/source_runs/` and `analysis/multieurlex/`.
These source snapshots are partial until the analysis says `matrix_complete`.
The original `casehold/analysis.json` is an earlier original-matrix snapshot;
use the newer extended path for this extension's progress.

```bash
python scripts/analyze_revision_v2.py --kind casehold --input papers/ipm/results/revision_v2/casehold/source_runs --fedadam-input papers/ipm/results/revision_v2/casehold_fedadam/source_runs --output tmp/reproduced_revision_casehold
python scripts/analyze_revision_multieurlex.py --input papers/ipm/results/revision_v2/multieurlex/source_runs --output tmp/reproduced_revision_multieurlex
```

The language analyzer reconstructs held-out micro F1 and checks identical test
IDs and gold labels across completed runs. Both commands were rerun locally on
the downloaded evidence. Source files contain numeric predictions and benchmark
identifiers; the benchmark text and model checkpoints remain with their providers
and the remote experiment workspace.
